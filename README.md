# 司导智能体工作台

移动端交互原型，无需构建。

启动：`python3 -m http.server 5173 --directory dist`

- 每屏一张任务卡片，上下滑动整页吸附；任务卡片压缩、对话面板原地上滑。
- 每天首次出车任务提供出车准备，同一天共用检查状态。
- 确认接单即结束确认任务，卡片移出待办，历史侧栏保留记录。
- 历史侧栏支持查看全部任务、新建任务；底栏为纯图标。
- 按客户、时间、当前处理任务和可见任务推断上下文。
- 三项出车检查完成后允许出发。
- 关闭恢复浏览位置，各任务保留独立会话。
- 浏览器支持时提供语音识别，识别内容经用户发送。

所有操作和历史记录仅保留在当前页面内存中，每次刷新恢复初始状态，不读取或写入本机存储。无真实 AI、路况或订单接口。电话链接调用设备拨号。

布局：桌面预览固定 390×844px，较小手机视口内自适应。抽屉与遮罩限制在手机容器中。应用内返回使用页面栈，保留上一层任务、列表位置、历史列表和新建表单。历史对话使用当前标题、返回箭头并隐藏任务数量。

联系乘客：按订单生成确认重点与沟通话术，语音联系调用设备拨号；发送按钮仅显示发送状态，不发送真实消息。

## 完整任务流程
- 接送服务使用九阶段顺序状态：开始出发 → 前往接驾点 → 即将到达接驾点 → 已到达 / 等待乘客 → 接到乘客 → 前往目的地 → 即将到达目的地 → 乘客下车 → 服务结束。
- 每阶段包含 AI 主动提醒、下一步按钮和输入建议；点击空输入框填入建议，发送后推进。旧阶段按钮不可重复执行，关闭对话后保留进度。
- 联系客户：整理话术 → 发送 → 确认沟通结果 → 归档。明日任务完成行前确认，不提前开始出车。
- 订单支持调价后确认接单；自建任务支持整理要求、记录处理结果与完成归档。
- 所有路线、乘客回复、消息发送和服务推进均为本地交互模拟，不连接外部服务；刷新清空状态。

新建任务改为对话输入，本地按首句提炼标题、保留补充内容作为说明，并更新同一任务卡片。接送阶段自动展示接近及到达通知，不再提供重复联系按钮；接送结束提示不展示金额。此原型仍使用本地规则模拟 AI 总结和乘客通知，不调用真实消息服务。

新建任务现为直接问答入口：对话和提炼的标题、说明仅进入历史任务，可重新打开继续问答，不创建首页待办。常见司导问题的回答与摘要使用本地规则模拟，尚未连接通用大模型。

## 复盘
第二个 tab 展示任务、客户、订单三张纵向吸附卡片，底部保留 AI 输入。统计排除问答记录；及时完成按完成时间不晚于截止时间计算，逾期指超过截止时间且尚未完成，占比以全部任务为分母。任务无独立截止字段时，以预约时间为截止时间，无具体时间则使用当日 23:59。
全部任务默认待办，支持全部、待办、逾期、已完成筛选。复盘对话独立归档，可从左上角打开续聊；与其他页面状态一致，刷新清空。AI 回答使用本地规则模拟。

复盘视觉更新：任务使用环形状态占比，客户使用预约日期分布条，订单使用报价柱状图。全部任务为独立二级页面，默认待办，返回保留复盘卡片位置。三个底部导航选中时切换 Phosphor 面性图标，未选中时为线性图标。

AI 建议置于数据指标下方，图表只显示数量或金额，不在图例中展示百分比。新增两条逾期及两条及时完成的任务，截止与完成时间相对页面加载时间生成。全部任务卡片补充最多两行自然语言描述，点击直接打开处理会话（已完成任务打开记录）；返回恢复来源页面、筛选及滚动位置，完成任务后同步刷新统计。

## 连续语音对讲
打开即通过 getUserMedia 请求麦克风，SpeechRecognition 开启 continuous 与 interimResults；“字”开关显示临时转写与完整对话。用户说话、AI 回答、静音和错误使用不同提示，按钮和光球提供轻微反馈。播报时暂停识别以避免识别自身声音，播报完毕恢复；关闭对讲或卸载页面释放媒体轨道、取消识别和播报。权限拒绝及不支持识别的浏览器显示重试/兼容性提示，不伪装成功。
语音捕获与转写依赖浏览器语音服务，不保存音频文件。回答与任务指令仍为本地规则模拟：支持上下文查询、出发（需先完成出车准备）、接单/接到乘客（需匹配阶段）、通知草稿，以及“发布”模拟发送，不连接真实订单和消息平台。新建任务页共用语音开关、对讲入口及微信样式胶囊按钮。

## AI 对话入口整合
底栏依次为任务、看板、AI 对话、我的，任务使用剪贴板图标。任务与看板首页移除历史侧栏入口，对讲仅在 AI 对话首页顶部展示，复盘对话页隐藏。AI 对话侧栏按任务、复盘-任务、复盘-客户、复盘-订单分组，支持继续历史会话和新建对话。看板每张卡片展示两条快捷建议和“想换个思路，和 AI 聊聊”，点击进入对应类型会话并以建议原文开始对话。会话仍只保存在页面内存中。

顶部标题居中，首页标题为“任务”；对讲位于语音播报左侧。任务和看板快捷建议均进入独立二级对话页面，隐藏底部导航，顶部返回恢复来源页面。看板默认不显示输入框，进入 AI 对话 Tab 时展示欢迎词，可从历史侧栏继续会话。

对话界面简化：移除正文上方的分类、标题及新对话栏；新建入口改为 AI 页顶部历史图标右侧的编辑图标，历史抽屉不再提供新建按钮。任务对话面板和输入区底色透明，输入框保持白色。删除遗失物品归还任务。任务卡片是否显示聊天入口由本地内容及状态规则决定：检查类任务不展示，沟通、议价、需求确认及服务中任务可展示；出车准备直接打开检查表。今日安排回答根据当前日期、预约时间、完成状态及报价生成，仍未接入真实大模型。

经营看板：客户卡片展示客户总数、客户转化率、渠道占比（黄小西/私域/其它）与客群分布（企业/高端/亲子/其它）；订单展示本月营收、营收分布（出行服务/佣金/其它）、成交订单数与订单转化率。使用独立的本月经营指标，客户转化率为已成交客户/客户总数，订单转化率为成交订单/有效询单。四个快捷问题提供对应的本地分析与沟通建议，不实际推送客户。AI 回复卡片统一白色，欢迎页移除插图，新建入口使用对话加号图标。

任务首页使用浅灰背景、问候与待办总数、蓝色叠层渐变任务卡与胶囊导航。首页展示全部未完成任务，数量随任务完成实时更新，保留原任务操作与上下滑动。仅任务首页应用卡片视觉。对讲文字空态改为“请说话”，左对齐，文字区域距页面两侧各 24px。

任务卡片支持随上下滚动的透视翻转，滚轮手势逐张切换，触屏继续使用整页吸附；系统开启减少动态效果时关闭透视与渐隐。主色为 #7286FF。四个底部导航使用提供的 PNG 图标，置于 50px 高的白色胶囊内，等宽分布，无文字，选中浅灰底、未选中透明；二级对话继续隐藏底栏。

任务卡片高度比宽度多 36px，滚动翻页时仅呈现当前卡及上下各两张，外层卡片渐隐；超出范围的待办仍可继续翻页。任务、看板、AI 对话页背景统一为 #F5F5F5，底部导航保留 50px 高度并在页面两侧各留 16px。

任务卡片恢复页面内宽度，高度比宽度多 36px；相邻卡片逐层提亮，内容分段加大间距。滚轮每次连续操作只翻一页，等待 150ms 后可再次操作；触屏滑动 70px 后每次只翻一页。卡片组整体上移 32px。

## 我的主页与橱窗
新增通栏背景图、头像、名字、简介、编辑主页与分享入口；任务、客户、订单、钱包横排。任务复用全部任务二级页，客户支持查看详情与电话链接，订单支持全部/进行中/待付款/待出行/退款售后筛选和详情，钱包展示可用余额、待入账、累计收入及最近账单。橱窗支持新增发布、编辑、图片上传和删除确认；主页可编辑名字、简介、头像与封面。分享使用系统分享或复制介绍和服务内容。所有资料及发布内容仍仅在内存中保存，刷新恢复初始演示数据；订单和钱包为示例，不连接交易服务。
